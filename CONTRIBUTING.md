# Contributing to service-edge-ai

Thank you for your interest in contributing to this Open Horizon service!

## Community Guidelines

This project follows the Open Horizon community contributing guidelines. Please review:

**[Open Horizon Contributing Guide](https://github.com/open-horizon/.github/blob/master/CONTRIBUTING.md)**

## Developer Certificate of Origin

All commits must be signed off with `git commit -s` to indicate agreement with the [Developer Certificate of Origin (DCO)](https://developercertificate.org/).

## Getting Started

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/amazing-feature`)
3. Make your changes
4. Commit your changes with sign-off (`git commit -s -m 'Add amazing feature'`)
5. Push to the branch (`git push origin feature/amazing-feature`)
6. Open a Pull Request

## Questions?

For questions about contributing to Open Horizon projects, please visit the [Open Horizon community resources](https://wiki.lfedge.org/display/OH/Open+Horizon).
