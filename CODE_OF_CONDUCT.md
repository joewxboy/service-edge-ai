# Code of Conduct

This project follows the Open Horizon community Code of Conduct.

Please review the official Code of Conduct at:

**[Open Horizon Code of Conduct](https://github.com/open-horizon/.github/blob/master/CODE_OF_CONDUCT.md)**

## Summary

The Open Horizon community is committed to providing a welcoming and inclusive environment for all contributors. We expect all community members to:

- Be respectful and considerate
- Welcome newcomers and help them get started
- Be collaborative and constructive
- Focus on what is best for the community

## Reporting Issues

If you experience or witness unacceptable behavior, please report it by contacting the project maintainers or following the reporting procedures outlined in the official Code of Conduct.

## Questions?

For questions about the Code of Conduct, please visit the [Open Horizon community resources](https://wiki.lfedge.org/display/OH/Open+Horizon).
